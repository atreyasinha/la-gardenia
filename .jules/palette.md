## 2025-02-12 - Keyboard Focus Visual Parity
**Learning:** Icon-only interactive elements lacking explicit \`onFocus\` event parity for visual feedback create a poor experience for keyboard users who rely on visual scaling cues typically triggered by hover states.
**Action:** Always replicate hover-triggered visual changes using \`onFocus\` and \`onBlur\` event handlers to ensure visual parity for keyboard navigation, particularly for floating action buttons.
