## 2026-07-25 - Adding IDs to Labels in ContactModal\n**Learning:** Missing 'htmlFor' and 'id' associations for form elements reduces accessibility for screen readers and breaks click-to-focus behavior for labels. While ARIA labels are good, semantic HTML labels with 'id' associations are the standard approach for simple forms.\n**Action:** Ensure all form inputs (<input>, <select>, <textarea>) have unique 'id' attributes and their corresponding <label> elements have matching 'htmlFor' attributes.

## 2026-07-26 - Providing ARIA States on Custom Toggle Buttons
**Learning:** Screen readers cannot determine the active/selected state of custom toggle button groups (such as category filters or tabs built with standard `<button>` elements) based solely on visual CSS changes (like swapping `.btn-outline` for `.btn-gold`). Without explicit state attributes, a visually impaired user won't know which filter or tab is currently active.
**Action:** Always ensure that custom button toggle groups and tabs utilize explicit ARIA state attributes, such as `aria-pressed="true"` for simple toggles or `aria-selected="true"` for strict tablists, bound dynamically to the component's active state variable.
