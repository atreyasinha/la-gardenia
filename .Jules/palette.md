## 2026-07-25 - Adding IDs to Labels in ContactModal\n**Learning:** Missing 'htmlFor' and 'id' associations for form elements reduces accessibility for screen readers and breaks click-to-focus behavior for labels. While ARIA labels are good, semantic HTML labels with 'id' associations are the standard approach for simple forms.\n**Action:** Ensure all form inputs (<input>, <select>, <textarea>) have unique 'id' attributes and their corresponding <label> elements have matching 'htmlFor' attributes.

## 2026-07-26 - Communicating Active State in Toggle Group Buttons
**Learning:** Custom UI controls in the project often use standard `<button>` elements acting as toggle groups or tabs (e.g., in `Venues.jsx`, `Gallery.jsx`, `CateringMenu.jsx`). While visual styling (like `.btn-gold` vs `.btn-outline`) conveys the active state to sighted users, screen reader users miss this context without explicit ARIA attributes.
**Action:** When implementing or modifying custom toggle groups or tab-like interfaces built with standard `<button>` elements, always add an `aria-pressed={isActive}` (or `aria-selected` for ARIA tablists) attribute to ensure the active/selected state is properly communicated to assistive technologies.
