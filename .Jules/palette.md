## 2026-07-25 - Adding IDs to Labels in ContactModal\n**Learning:** Missing 'htmlFor' and 'id' associations for form elements reduces accessibility for screen readers and breaks click-to-focus behavior for labels. While ARIA labels are good, semantic HTML labels with 'id' associations are the standard approach for simple forms.\n**Action:** Ensure all form inputs (<input>, <select>, <textarea>) have unique 'id' attributes and their corresponding <label> elements have matching 'htmlFor' attributes.

## 2024-11-20 - Adding ARIA labels and focus states to icon-only links
**Learning:** Icon-only links (such as floating action buttons) require explicit `aria-label` attributes to ensure proper screen reader accessibility, even if a `title` attribute is present, as `title` attributes are not consistently announced by assistive technologies. Furthermore, replicating hover-triggered visual changes (like scaling) using `onFocus` and `onBlur` event handlers ensures visual parity and a better experience for keyboard users.
**Action:** Always provide `aria-label` attributes for icon-only links or buttons, and verify that interactive elements have distinct focus states for keyboard navigation that mimic their hover states.
