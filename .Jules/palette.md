## 2026-07-25 - Adding IDs to Labels in ContactModal\n**Learning:** Missing 'htmlFor' and 'id' associations for form elements reduces accessibility for screen readers and breaks click-to-focus behavior for labels. While ARIA labels are good, semantic HTML labels with 'id' associations are the standard approach for simple forms.\n**Action:** Ensure all form inputs (<input>, <select>, <textarea>) have unique 'id' attributes and their corresponding <label> elements have matching 'htmlFor' attributes.

## 2024-09-06 - Adding aria-pressed to custom toggle buttons
**Learning:** Custom UI controls like `<button>` elements acting as toggle groups or tabs require explicit ARIA state attributes (like `aria-pressed` or `aria-selected`) for proper screen reader accessibility. Just relying on visual class changes (like `btn-gold` vs `btn-outline`) is insufficient.
**Action:** When implementing custom toggle button groups, ensure an `aria-pressed` or `aria-selected` attribute dynamically reflects the button's active state.
