## 2026-07-25 - Adding IDs to Labels in ContactModal\n**Learning:** Missing 'htmlFor' and 'id' associations for form elements reduces accessibility for screen readers and breaks click-to-focus behavior for labels. While ARIA labels are good, semantic HTML labels with 'id' associations are the standard approach for simple forms.\n**Action:** Ensure all form inputs (<input>, <select>, <textarea>) have unique 'id' attributes and their corresponding <label> elements have matching 'htmlFor' attributes.
## 2026-07-26 - Floating Action Button Keyboard Accessibility
**Learning:** Icon-only floating action buttons using `<a>` tags require explicit `aria-label` attributes for screen readers, as `title` attributes alone are not reliably announced. Additionally, replicating hover-triggered visual changes (like CSS scaling on `onMouseEnter`) with `onFocus` and `onBlur` handlers is essential for providing visual parity and clear focus states to keyboard users.
**Action:** Always provide explicit `aria-label` attributes to icon-only interactive elements and ensure visual hover states are mirrored as focus states for keyboard accessibility.
