## 2026-07-25 - Adding IDs to Labels in ContactModal\n**Learning:** Missing 'htmlFor' and 'id' associations for form elements reduces accessibility for screen readers and breaks click-to-focus behavior for labels. While ARIA labels are good, semantic HTML labels with 'id' associations are the standard approach for simple forms.\n**Action:** Ensure all form inputs (<input>, <select>, <textarea>) have unique 'id' attributes and their corresponding <label> elements have matching 'htmlFor' attributes.

## 2026-07-25 - ARIA States for Custom UI Toggle Groups
**Learning:** Custom UI controls in the project that use standard `<button>` elements acting as toggle groups or tabs require explicit ARIA state attributes (like `aria-pressed` or `aria-selected` or `aria-current`) for proper screen reader accessibility. Otherwise, assistive technologies cannot announce which tab/filter/slide is currently active.
**Action:** Ensure all custom toggle buttons or tab-like components have `aria-pressed`, `aria-selected`, or `aria-current` dynamically updated to reflect their active state.
