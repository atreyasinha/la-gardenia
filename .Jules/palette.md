## 2026-07-25 - Adding IDs to Labels in ContactModal\n**Learning:** Missing 'htmlFor' and 'id' associations for form elements reduces accessibility for screen readers and breaks click-to-focus behavior for labels. While ARIA labels are good, semantic HTML labels with 'id' associations are the standard approach for simple forms.\n**Action:** Ensure all form inputs (<input>, <select>, <textarea>) have unique 'id' attributes and their corresponding <label> elements have matching 'htmlFor' attributes.
## 2024-08-10 - ARIA States for Button Toggle Groups
**Learning:** Found a recurring pattern in this app's components (Venues, Gallery, CateringMenu) where standard `<button>` elements are styled and used collectively as toggle groups (tabs/filters) to swap content. Because standard buttons don't inherently communicate an "active" or "selected" state to assistive technologies, screen reader users had no way of knowing which tab or filter was currently active.
**Action:** Always ensure that when `<button>` elements are repurposed as toggle groups or tabs in this design system, the active/selected state is explicitly communicated using attributes like `aria-pressed="true"` or `aria-selected="true"`.
