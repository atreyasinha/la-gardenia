## 2026-07-25 - Adding IDs to Labels in ContactModal\n**Learning:** Missing 'htmlFor' and 'id' associations for form elements reduces accessibility for screen readers and breaks click-to-focus behavior for labels. While ARIA labels are good, semantic HTML labels with 'id' associations are the standard approach for simple forms.\n**Action:** Ensure all form inputs (<input>, <select>, <textarea>) have unique 'id' attributes and their corresponding <label> elements have matching 'htmlFor' attributes.

## 2024-05-18 - Missing keyboard focus visual parity on interactive Floating Actions
**Learning:** Icon-only interactive elements (like the WhatsApp Floating Action Button) might employ CSS transform (scale) on mouse enter/leave but fail to apply these same visual cues on keyboard focus (tabbing). Without onFocus/onBlur matching the onMouseEnter/Leave states, keyboard users are left wondering which element is active when tabbing through the page. Additionally, an explicit aria-label is necessary for screen readers, as the "title" attribute isn't universally announced.
**Action:** Always verify that interactive components leveraging visual changes (like scale/color transforms) on hover bind those identical changes to `onFocus` and `onBlur` for keyboard parity, and confirm `aria-label` is present on icon-only interactive controls.
